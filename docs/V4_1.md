# VetorizaFB 4.1.0

This branch keeps the classic Tk interface, including the 4.0.6 selection,
automatic dimensions, live preview, zoom, review shortcuts, project files,
proxy/model dialog and XYZ export. The Qt workbench is optional, not the default.

## Windows

```powershell
git fetch origin
git switch v4.1-folhas-de-bordo
git pull --ff-only
.\.venv\Scripts\python.exe -m pip install -e ".[ocr,test]"
.\.venv\Scripts\vetorizafb-gui.exe
```

Prepare > Modo now offers Realce, Bruto and Folha de bordo. FB uses background
normalization/local contrast, preserves 1–3 digit readings per box and uses a
separate geometric grouping path for smaller lower decimetres without the CN
31 m restriction. Preview never executes OCR. FB remains experimental: its
coordinate anchor and 690-reference accuracy require independent validation.

Reconhecer > Revisar leituras opens a compact secondary window with original
image crops, confidence, raw text, uncertain/unassigned filter and correction.
An empty corrected token is rejected. FB allows multiple digits. Corrections
retain prior evidence and invalidate grouping. Select several rows with Ctrl or
Shift to join boxes; split one box horizontally/vertically by an internal pixel
offset. Geometry edits invalidate all readings; run Reconhecer again. Existing
review replacement prompts apply before edits. Save the project to retain edits.
In the Dígitos map layer, clicking an FB token opens this review directly.

All new FB processing is shared with the 5.0 experiment. Realce/Bruto retain
single-digit CN handling. Source TIFFs and generated outputs stay outside Git.
The whole-raster classic loader remains; the separate windowed experiment is
not connected to the GUI. No new handwriting model is downloaded automatically.
